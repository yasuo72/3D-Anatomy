# Anatomy Lab 3D ✦ 3D Human Anatomy Explorer

Developed & Maintained by **Rohit**.

An interactive, high-performance 3D human anatomy explorer built with **Three.js**, **React 19**, **Next.js**, and **TailwindCSS**.

## 🌟 Key Features

- **Interactive 3D Specimen Viewer:** Explore medically accurate 3D models of organs (Heart, Brain, Lungs, Liver, Kidneys, Eyeball, Intestine, Pancreas, Skin).
- **Dual Light & Dark Mode:** Sleek, high-contrast dark theme alongside warm studio light theme with smooth switching.
- **X-Ray & Dissection Exploded View:** Smooth sliders for translucency and 3D sub-mesh separation.
- **Live ECG & Pulse HUD Overlay:** Real-time pulse waveform monitor.
- **Web Audio Soundscapes & Voiceovers:** Self-contained ambient heartbeat/breathing sound synth and voiceover speech synthesis.
- **Interactive 3D Quiz & Notes Export:** Take quizzes and export personal study notes to `.txt`.

## 🚀 Getting Started

### Prerequisites

- Node.js `>=22.13.0`

### Installation & Run

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

## 🛠️ Built With

- **Framework:** Next.js / Vinext
- **3D Graphics:** Three.js, GLTFLoader, MeshoptDecoder
- **Styling:** Custom CSS Design System + TailwindCSS
- **Animations:** GSAP & Lucide Icons
